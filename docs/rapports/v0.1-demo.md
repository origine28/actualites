## 17. Limitations connues

| Limitation | Impact |
|---|---|
| Pas de rich text editor | Le contenu HTML est ecrit en brut |
| Pas de stockage R2 | Fichiers sur disque local |
| Pas de CDN | Pas de distribution de contenu |
| Pas de CAPTCHA | Pas de protection anti-bot avancee |
| Pas de rotation de sessions | Sessions TTL 24h avec sliding window |
| Limite 100 Mo par fichier | Compatible Cloudflare Free/Pro |
| Pas de systeme de commentaires | Hors perimetre V0.1 |
| Pas de newsletter | Hors perimetre V0.1 |
| Pas de monitoring production | Hors perimetre V0.1 |
| Quick Tunnel temporaire | URL change a chaque relance, pas de SLA |
